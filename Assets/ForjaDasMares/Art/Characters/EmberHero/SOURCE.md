# Emberheart Hero

Personagem fornecido pelo titular do projeto no arquivo Meshy_AI_Emberheart_Hero_biped.zip. Crédito: Model created with Meshy. Originais preservados; nenhum recurso de Dungeon Rampage foi utilizado.

12.618 triângulos, 72 ossos, uma malha com skin, um material e texturas PBR originais. Integração URP, altura visual configurada em 1,80 m e limite visual de 1,10 m para espada/machado. A classe e os dados de combate continuam sendo Guerreiro/Brasa.

EmberHero.fbx é o corpo original. EmberRunningSource.fbx é a corrida fornecida (19 frames). EmberAnimated.fbx contém 25 clips: corrida fornecida copiada para o mesmo esqueleto, sem deslocamento da raiz, e demais ações originais geradas no Blender. Fonte comprimida em ArtSource/Characters/EmberHero; gerador compartilhado ArtSource/Characters/SapphireMage/animate_sapphire.py, opção --warrior.

Android preparado com texturas ASTC6x6/1024, PC2048. Não houve build/teste Android nesta integração.
